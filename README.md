# Sentiment-Analysis-Of-British-Airways-Customer-Reviews-Using-Google-Cloud-Platform (GCP)



The primary objective of this project is to analyze sentiment from customer reviews stored in a structured dataset. By leveraging Google Cloud’s Natural Language API, the system will process textual data, determine sentiment polarity and quantify the emotional magnitude of each review. The insights gained will help businesses improve decision-making, enhance customer experience and respond proactively to feedback.




This project includes the following key tasks:-


• **Data Preprocessing:** Cleaning and formatting textual data from the given dataset.


• **Google Cloud API Integration:** Utilizing Google Cloud Natural Language API to perform sentiment analysis.


• **Sentiment Score & Magnitude Calculation:** Assigning scores to customer reviews based on sentiment polarity (positive, neutral and negative).


• **Data Storage & Visualization:** Saving analyzed data and generating insights using statistical visualization techniques.


• **Result Interpretation:** Providing actionable insights based on sentiment trends.
